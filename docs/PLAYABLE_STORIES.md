# Share a playable Game episode

Choose a saved game in the Game room, then select **Share playable story** in the director or scene player. Choose **Save HTML file** and a new filename outside the project. Share that single file. Readers open it in a browser with JavaScript enabled, including while offline.

Tidal Relay includes its six authored routes and any additional saved branches. For a model-written episode, the reader offers moves that have a saved response. Readers start at the opening, use the choice buttons or keys 1–9, and can go back or replay. Each export contains just the selected episode.

For an imported legacy Game save, select the imported branch and choose **Continue this Game branch** to open its saved turns in the director before sharing.

The export embeds available scene guides and poster images as compressed stills. If a turn has saved narration, enable **Include saved turn narration** to include the latest recording for that turn. Readers control playback. The exporter allows up to 2 MiB of PCM per recording, with separate 6 MiB budgets for artwork and speech. Studio reports how many scenes, images and recordings were saved and how many media items it skipped. Video takes and live generation stay in the desktop project.
